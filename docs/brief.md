# Техническое задание

Вариант 12. Пользователь сравнивает население Беларуси с соседями, прослеживает изменения по годам и сверяет графики с таблицей. Источник — открытые годовые ряды Всемирного банка.

Сценарии приёмки

1. Выбрать страну и диапазон лет, прочитать численность и изменение.
2. Сравнить результат с другими странами в конце периода.
3. Отсортировать и отфильтровать исходные записи.
4. Импортировать собственный CSV и увидеть сообщение об ошибке при некорректном вводе.
5. Открыть сохранённый вид встроенного набора по ссылке.
6. Пройти тот же сценарий с клавиатуры и на экране шириной 360 px.
